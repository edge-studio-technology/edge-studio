# 0043: License Edge Studio under MIT

**Status:** Accepted
**Date:** 2026-11-16

## Context

The public contribution journey supports local forks and reviewed source contributions, but the project had no project-wide license. Contributors needed explicit permission to use, modify and share the code.

## Decision

Use the standard MIT License for Edge Studio code and documentation, as requested by the project owner. Contributions are accepted under the same MIT terms; contributors retain their copyrights. No separate CLA, DCO or copyright assignment is required. Third-party dependencies and separately licensed material retain their own licenses and notices.

## Alternatives considered

- Leaving licensing unresolved would keep the public-code contribution gate open.
- A copyleft or custom license was not selected; the owner requested MIT's permissive terms.

## Consequences

People may modify, redistribute and commercially use Edge Studio subject to the MIT notice requirements. The license does not require modified versions to publish their source. The standard warranty disclaimer applies. Maintainer review, release ownership and contributor trials remain separate responsibilities.
