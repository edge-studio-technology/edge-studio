- User noticed a brief flash when the confirm modal swaps to the progress modal. Root cause was in the shared `Modal` (`components/ui/Modal.tsx`): it held a `mounted` state that started `false` and only flipped `true` in a post-commit `useEffect`, returning `null` on the first render otherwise. That's dead weight (no CSS transition was gated on it, and this is a pure client-side Vite app, no SSR hydration concern) — but it meant every newly-mounted `Modal` was invisible for one commit. When two modals swap in the same click handler (both state updates batch into one React commit), the old modal's portal disappears and the new modal's first render is still gated `null`, producing one paint with neither visible. Removed the `mounted` gate entirely (and the now-unused `useState` import) so `Modal` renders on its actual first render. This fixes the flicker for every modal-to-modal swap in the app, not just backup delete. Verified with `npm --prefix frontend run build`. Recorded the rationale in `docs/adr/0005-modal-mount-gate-removal.md` (not linked from `CHANGELOG.md`, per user request).
